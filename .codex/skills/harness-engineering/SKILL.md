# Harness Engineering

Codex는 이 스킬을 사용할 때 `.ai/skills/harness-engineering/SKILL.md`와
`docs/conventions/ai_harness_engineering.md`를 우선 기준으로 따릅니다.

## 핵심 규칙

1. 작업 시작 전 화면 스펙과 컨벤션 문서를 읽습니다.
2. Kotlin 파일 수정 후 `.ai/hooks/post_edit_lint.sh`로 컴파일을 검증합니다.
3. 화면 스펙 변경 시 `docs/` 문서를 같은 작업에서 함께 업데이트합니다.
4. 커밋과 PR은 `docs/conventions/commit_conventions.md`를 따릅니다.
