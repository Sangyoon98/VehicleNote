# 실수 로그 (Mistakes Log)

> AI가 잘못된 결과를 제공하거나 실수를 한 경우 이 문서에 기록합니다.
> 새 대화를 시작할 때 이 문서를 읽어 같은 실수를 반복하지 않도록 합니다.
>
> **기록 방법**: 실수 발생 시 아래 템플릿에 따라 항목을 추가하세요.
> **AI 지침**: 작업 시작 전 이 문서를 확인하고, 유사한 작업이면 관련 항목을 검토하세요.

---

## 템플릿

```markdown
### [M-NNN] {실수 제목}
- **날짜**: YYYY-MM-DD
- **상황**: 어떤 작업을 하다가 발생했는지
- **실수 내용**: 구체적으로 무엇을 잘못했는지
- **영향**: 어떤 문제가 생겼는지
- **올바른 방법**: 어떻게 했어야 하는지
- **재발 방지**: 앞으로 이런 상황에서 어떻게 행동할지
```

---

## 실수 목록

### [M-001] 기능 구현 후 문서 업데이트 누락
- **날짜**: 2026-04-13
- **상황**: 설정 화면(Settings) 신규 기능을 구현하는 작업
- **실수 내용**: 기능 구현을 완료한 후 관련 문서(`docs/08_settings.md`)를 자동으로 작성하지 않았음. 사용자가 별도로 지적한 후에야 문서를 작성함
- **영향**: 문서와 코드 간 동기화가 깨질 뻔함
- **올바른 방법**: 기능 구현이 완료되는 시점에 `docs/` 내 해당 화면 문서를 함께 생성 또는 업데이트해야 함
- **재발 방지**: 코드 작업이 끝나면 반드시 관련 `docs/*.md`를 확인하고, 신규 화면이면 생성, 기존 화면 수정이면 해당 문서를 업데이트한다. 사용자가 말하지 않아도 문서 업데이트는 작업의 일부임

---

## 패턴별 주의사항

AI 작업 중 반복적으로 발생하기 쉬운 일반 패턴을 정리합니다.
실수 로그가 쌓이면 공통 패턴을 이곳에 요약합니다.
